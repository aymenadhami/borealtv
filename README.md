# borealtv
An html Windows TV Launcher with youtube integration and TMDB API Integration

Use your own TMDB API key to load shows and trailers.

Create or sign in to your TMDB account.
Open Settings → API in a desktop browser and request an API key. Complete TMDB’s application and accept its terms.
Copy your API Key (v3 auth) and paste it below. Use the API key, not the longer API Read Access Token.
TMDB API key
Paste your API key
A key is saved on your local machine.
